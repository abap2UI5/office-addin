unreleased
----------
+ The add-in: abap2UI5 apps in the task pane of Microsoft Excel, with the real abap2UI5 UI5 frontend. The host page - the BSP application Z2UI5_XL, pulled with abapGit - loads Office.js from Microsoft's CDN, boots the system's UI5 and embeds the abap2UI5 app with z2ui5.embed.Container (@abap2ui5/embed-control 0.1.1) on the system's own origin; the app is the URL parameter app. Outside Office the page runs the same app with a message, for testing in a browser
+ Demo app Z2UI5_CL_XL_DEMO: a material list with Export to Excel (a new sheet with an Excel table), Take selection (the selected cells into the app), Follow selection and the bridge's errors, through z2ui5.cc.ExcelBridge - needs the abap2UI5 release with pull request #2847
+ npm run manifest: the add-in only manifest (XML) for one system and app - task pane, Excel, ReadWriteDocument, ExcelApi 1.4, a button on the Home tab - from manifest/manifest.template.xml, with a stable id, client, theme, startup parameters and extra app domains
+ npm run dist and examples/approuter: the host page without a BSP, behind an SAP approuter on the system's origin (documented, not tested)
+ CI: abaplint (Standard, Cloud, 7.02), the abap2UI5 linter, the generated BSP against its sources, the manifest offline and through Microsoft's validation service, and a Playwright smoke test of the host page against a stub of Office.js on UI5 1.136 and 1.71
