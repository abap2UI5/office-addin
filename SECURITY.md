# Security

Please report a vulnerability privately through GitHub's security advisories
of this repository (Security > Report a vulnerability), not as a public
issue. A finding in the abap2UI5 framework or the `z2ui5.cc.ExcelBridge`
control belongs to https://github.com/abap2UI5/abap2UI5, one in the embed
control to https://github.com/abap2UI5/embed-control.
